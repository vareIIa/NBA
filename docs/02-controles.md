# 02 — Controles (idênticos ao NBA 2K23)

> **Decisão D6**: os controles são **os mesmos do 2K**. A base é o **manual oficial do NBA 2K23** (Xbox Series e PS5). O mapa central não mudou até o 2K27; as diferenças posteriores estão no fim.
> Notação: **RS** = Pro Stick. As direções assumem a bola na **mão direita**; com a esquerda, espelhe esquerda/direita.
> Equivalências PlayStation: A=✕ · B=◯ · X=□ · Y=△ · LB=L1 · RB=R1 · LT=L2 · RT=R2 · View=touchpad · Menu=Options.
> Confiança: **H** = manual oficial/Courtside Report · **M** = fontes da comunidade consistentes (ou lista do 2K24, herdada do 2K23) · **L** = fonte única/inferência.

## 0. Orientação do Pro Stick

Configuração **Orientação do Pro Stick**: **Absoluta** (padrão) ou **Relativa à câmera**.
- **Absoluta**: as direções seguem o **corpo do jogador**. Cima = para frente (para onde ele ataca), direita = lado da mão da bola, esquerda = mão livre.
- **Relativa à câmera**: as direções seguem a tela.
- Ataque sem bola e defesa têm configurações de orientação próprias, com as mesmas duas opções. **(H)**

## 9. Configurações (iguais às do 2K23)

- **Timing do arremesso**: Só arremessos / Só bandejas / Arremessos e bandejas / Real Player %. Real Player % não vale no online.
- **Momento de soltura** (2K23: "Shot Timing Release Time"): Muito cedo / Cedo / Tarde / Muito tarde. Escolhe **onde** na animação fica o ponto ideal.
- **Medidor**: ligado / desligado / só lance livre / só botão / só Pro Stick. Desligado = janela um pouco maior.
- **Feedback de arremesso**: ligado/desligado.
- **Timing de lance livre**: do usuário / Real Player %.
- **Função do Pro Stick**: padrão / só dribles / só arremessos.
- **Orientação do Pro Stick** (ataque, sem bola, defesa): absoluta / relativa à câmera.
- Opções de passe: Skip Pass, Receiver Control (padrão / handoff-pitch / controle total).
