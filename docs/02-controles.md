# 02 — Controles

> Princípio: **um botão, uma intenção.** Contexto refina a ação, mas nunca troca a intenção do jogador.
> Todos os controles são remapeáveis. Layouts abaixo usam nomes do controle Xbox (PlayStation entre parênteses).

## 1. Ataque — com a bola

| Input | Ação | Detalhes |
|---|---|---|
| **LS** | Mover | Velocidade proporcional à inclinação |
| **RT (R2)** | Sprint | Gasta energia; dribles em sprint são mais rápidos e mais arriscados |
| **RS (R3 direcional)** | Dribles (Pro Stick) | Ver tabela de dribles em `05-gameplay-ataque.md` |
| **RS (puxar ↓ e empurrar ↑)** | Arremesso analógico | Modo Shot Stick (opcional) |
| **X (□)** | Arremessar (segurar/soltar) · toque = pump fake | Perto do aro vira bandeja/enterrada por contexto |
| **A (✕)** | Passe direto | Para o companheiro na direção do LS (ou ícone) |
| **B (◯)** | Passe quicado | Segurar = passe flashy (no-look/por trás) |
| **Y (△)** | Lob / alley-oop | Segurar perto da cesta = alley-oop para si mesmo na tabela (P2) |
| **LB (L1)** | Passe por ícone | Mostra ícones sobre companheiros; aperta o botão do ícone |
| **RB (R1)** | Pedir corta-luz | Segurar = escolher o tipo (pick & roll / pick & pop / slip) |
| **LT (L2)** | Post-up / proteger bola | Segurar com LS = back-down |
| **LT + RS** | Movimentos de post | Drop step, giro, up-and-under, hook |
| **RT + X** | Enterrada (na zona) | RS escolhe estilo |
| **D-pad** | Jogadas rápidas, ajustes, emotes (streetball) | ↑ jogadas · ← → estratégia · ↓ tempo/sub/emote |

## 2. Ataque — sem a bola (modo Carreira e 3x3)

| Input | Ação |
|---|---|
| **A (✕)** | Pedir a bola (tocar) · segurar = pedir lob / mostrar que está livre |
| **RB (R1)** | Fazer corta-luz (ir até o portador) · segurar = escolher alvo |
| **X (□)** | Corte rápido (backdoor/V-cut na direção do LS) |
| **Y (△)** | Pedir alley-oop |
| **LT (L2)** | Selar o defensor (post seal) / box-out |
| **RT (R2)** | Sprint |

## 3. Defesa

| Input | Ação | Detalhes |
|---|---|---|
| **LS** | Mover | Sem segurar nada = corrida normal |
| **LT (L2)** | Postura defensiva intensa | Deslize lateral, mais rápido para cortar o caminho, gasta energia |
| **RT (R2)** | Sprint | Para recuperar; perde postura |
| **X (□)** | Roubo | Timing com a **exposição da bola** (ver `06-gameplay-defesa.md`) |
| **Y (△)** | Toco / rebote | Direção do LS escolhe o tipo de salto |
| **RS** | Contestação de mão | ↑ mão alta (sem pular) · direções = mão no lado do drible |
| **A (✕)** | Trocar de jogador | Para o mais próximo da bola (fora do modo Carreira) |
| **B (◯)** | Tomar carga | Segurar no caminho do atacante; se o atacante tiver posição, falta de bloqueio |
| **LB (L1)** | Troca por ícone / pedir ajuda | Pede dobra no portador |
| **RB (R1)** | Chamar troca (switch) no corta-luz | — |

## 4. Teclado e mouse (PC)

| Tecla | Ação |
|---|---|
| WASD | Mover |
| Shift | Sprint |
| Espaço | Arremessar (segurar/soltar) |
| Mouse direito + direção do mouse | Pro Stick (dribles / contestação) |
| Q | Passe direto · E | Passe quicado · R | Lob |
| F | Post-up / postura defensiva |
| C | Corta-luz · V | Pedir bola |
| Botão esquerdo | Roubo (defesa) · Botão direito | Toco |
| 1–4 | Passe por ícone |
| Tab | Jogadas |

## 5. Regras de input

- **Buffer de input**: 150 ms (ver `04-animacoes.md`).
- **Deadzone** do RS configurável; dribles exigem "flick" (ir e voltar em < 200 ms) para não disparar sem querer.
- **Assistências opcionais** (Acessibilidade): auto-sprint, auto-drible simples (botão único faz combos), arremesso assistido, mira de passe assistida, vibração para timing do arremesso, indicador sonoro do ponto de soltura.
- **Modo canhoto**: espelha RS ↔ LS e gatilhos.
